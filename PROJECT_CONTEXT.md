# Project Context

## Purpose

This repository contains a Canadian SFOC-RPAS application prototype for public safety and Drone as First Responder (DFR) operations. It is intended to help explore how DroneSense Airbase-style workflows could support Canadian RPAS compliance planning, risk assessment, and application drafting.

## Target Users

The prototype is designed for public-sector and public-safety RPAS operators, including:

- Police services
- Fire departments
- Search and rescue teams
- Government RPAS operators

## Intended Use

This tool is intended for pre-SFOC planning and document generation. It helps operators organize application information, operational details, risk assessment inputs, mitigations, and draft supporting narratives before submitting materials through the appropriate Transport Canada process.

## Important Disclaimer

This prototype is not an official Transport Canada form, service, or submission system. Any generated content must be reviewed carefully against current Transport Canada requirements, official forms, advisory circulars, and operational approvals before use.

## Current Features

- Scenario templates for representative Canadian public safety / DFR operations
- Interactive map drawing for operational-area planning
- SORA/GRC logic for estimating Ground Risk Class, Air Risk Class, and SAIL level
- Mitigation selection for detect-and-avoid and CONOPS support
- Operational narrative generation for SFOC-RPAS application support
- Browser print / save-as-PDF output for draft documentation

## Coding Instruction

Preserve existing functionality unless specifically asked to change it. Changes should be scoped carefully so scenario loading, map drawing, SORA/GRC calculation, mitigation selection, narrative generation, and PDF/print output continue to behave as expected.
